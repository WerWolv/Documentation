Types to work with machine code


## Types

### `hex::type::Instruction`

A machine code instruction which will get disassembled
- `<DisassemblerSetting>`: A string containing the config for the disassembler in the form of "architecture; setting1, setting2, no-setting3"
- `<SyntaxType>`: Syntax used in the disassembly. Possible values are "intel", "at&t", "masm" and "motorola"
- `<ImageBaseAddress>`: Start address of the instruction region in the data
- `<ImageLoadAddress>`: Address where the instructions will be loaded into memory

Possible Values for DisassemblerSetting:
- Architecture, all may be suffixed with le or be to specify endianess (e.g armbe or mipsle)
